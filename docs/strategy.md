# 記事の方針（自動執筆が参照する）

## 基本
- テーマ「固定費の見直し」。カテゴリ：ガス／スマホ／ネット／保険／電気／家計全体
- 1つのテーマを関連記事で深掘りして、記事どうしを内部リンクでつなぐ
- 広告リンク登録済みの案件（`src/data/programs.ts` で url があるもの）を使える記事を優先
- 既存記事と同じ検索意図の記事は書かない（`src/content/posts/` を確認）

## 季節カレンダー
| 時期 | 優先テーマ | 例 |
|---|---|---|
| 11〜12月 | ガス（冬にガス代が上がる） | 賃貸でプロパンガスが高いとき／ガス会社切り替えの手順と注意点／プロパンガスの値上げ通知が来たら |
| 12〜1月 | ネット（1〜3月の引っ越しシーズン前） | 引っ越しのネット手続き／工事待ちの間のネット／光回線の解約金・工事費残債 |
| 1〜3月 | 保険・家計全体（年明けの見直し） | 保険の見直しタイミング／FP無料相談で聞くこと／固定費の年間点検 |
| 通年 | スマホ | キャリアから格安SIMへの乗り換え手順／家族のスマホ代／データ量の選び方 |

## 運営者の体験
- 運営者は、体験談に使ってよい情報を会話の中で直接 Claude に伝える。**このリポジトリは公開設定なので、運営者の個人的な数字はここに書かない**
- 体験談がない記事では、`{/* TODO（運営者）: ... */}` で追記を依頼する
