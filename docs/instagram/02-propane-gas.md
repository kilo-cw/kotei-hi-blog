# 投稿2：プロパンガス代、高すぎない？

## 本文
```
冬になってガス代、急に上がってませんか？🥶

プロパンガス（LPガス）って、
実はガス会社が料金を自由に決められる「自由料金」なんです。

だから、同じ地域・同じ使い方でも
会社によって料金が違うことも…！

まずは検針票でこの2つをチェック👇
① 基本料金
② 従量単価（1㎥あたりの料金）

比べるべきは「総額」じゃなくて「単価」。
冬は使う量が多いから、総額だけ見ても高いのか分からないんです💡

持ち家なら、ガス会社の切り替えで下がる可能性も。
賃貸の人は、まず管理会社に相談してみてね。
```
