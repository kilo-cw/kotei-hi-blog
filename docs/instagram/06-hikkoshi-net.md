# 投稿6：引っ越しのネット手続き、いつ何する？

元記事: /posts/hikkoshi-net-tetsuzuki/
画像: images/06-hikkoshi-net/

## 本文
```
引っ越し先で「ネットが使えない…」ってならないために📦

ネット回線は、申し込んでからすぐ使えるとは限りません。
開通工事が必要だったり、時期によっては工事の予約が混んでいたり。

引っ越しが決まったら、まず確認👇
① 新居のネット設備（光コンセント・ネット無料物件か）
② 今の回線の契約（解約金・工事費の残り）
③ スマホとのセット割

「移転」か「乗り換え」かは、トータルの費用で比べてね。
工事待ちの間のネットも、先に考えておくと安心です☺️

📌 保存して、引っ越しが決まったら見返してね
👉 手続きスケジュールはプロフィールのリンク（ブログ）から
```
